# [Official gli.al Webpage](https://gli.al)

[![Deploy to GitHub Pages](https://github.com/gliology/gliology.github.io/actions/workflows/hugo.yml/badge.svg)](https://github.com/gliology/gliology.github.io/actions/workflows/hugo.yml)

One-page [Hugo](https://gohugo.io) site for gli.al, the infrastructure practice of [F.R.E.D.](https://fred.build)
Based on Paradigm Shift by [HTML5 UP](https://html5up.net)

Services and principles are the files in `data/`. Their icons come from a subset of Nerd Fonts, so
run `design/subset-fonts.py` (needs Nix) after adding one.

Bundled fonts: Source Sans Pro and Raleway under the [SIL Open Font License 1.1](https://openfontlicense.org),
icons from [Nerd Fonts](https://www.nerdfonts.com).
